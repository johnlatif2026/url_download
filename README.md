# Media Downloader

تطبيق ويب لتحميل الفيديوهات والصوت من YouTube ومنصات التواصل الاجتماعي.

## المميزات

- ✅ دعم كامل لـ YouTube (MP4/MP3)
- 🎨 واجهة مستخدم عربية حديثة (Glassmorphism)
- ⚡ تحميل مباشر بدون تخزين مؤقت
- 🛡️ معالجة الأخطاء بشكل آمن
- 📱 تصميم متجاوب لجميع الأجهزة

## التثبيت والتشغيل

### المتطلبات الأساسية
- Node.js (v16 أو أحدث)
- npm أو yarn
